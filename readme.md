# 🚀 TaskFlow API

API de gerenciamento de tarefas desenvolvida com Python e FastAPI.

## 🛠️ Tecnologias
- Python
- FastAPI
- Pydantic
- Uvicorn

## 📋 Como rodar o projeto
1. Clone o repositório
2. Instale as dependências: `pip install fastapi uvicorn`
3. Execute o servidor: `python -m uvicorn main:app --reload`
4. Aceda à documentação em: `http://127.0.0.1:8000/docs`
